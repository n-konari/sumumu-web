ABOUT SUMUMU すむむ。について

すむむ。は理想の住み替えができるサービスです

情報は多いのに、信頼できるアドバイスがない。そんな住み替えの課題を解決するために、すむむ。は生まれました。
先輩の体験談・無料の住み替え支援・シミュレーションツールを一体で提供し、あなたの理想の住み替えをサポートします。

TOOLS 住み替えシミュレーション

住み替えを、シミュレーションする

数字で確かめてから動く。すむむ。のシミュレーションは「計算→先輩の体験談で照らし合わせ→コンシェルジュに相談」が一気通貫。一般的なポータルの計算ツールとは、設計思想が違います。

一般的な計算ツールとの違い
先
計算結果から先輩の体験談へ
同じ条件で実際に買った先輩の声を参照できる。数字が"自分ごと"になる。
相
結果をそのままコンシェルジュに共有
シミュレーション結果を持ち込んで無料相談。たたき台が整った状態で話せる。
中
販売・仲介なし、中立な立場
営業・勧誘は一切なし。あなたの住み替えを純粋にサポートするためのツール。
TOOL 01
ローン返済シミュレーター
借入額・金利・返済期間を入力するだけで、月々の返済額と総返済額を瞬時に算出。変動金利・固定金利の切り替えや繰り上げ返済の効果も確認できます。
⏱ 約2分 返済額を計算する
TOOL 02
借入可能額 & 住み替え資金計画
年収・返済負担率から無理のない借入可能額を試算。現マンション売却を検討中の方は、売却額→残債控除→新居購入の資金フローを一括でシミュレーションできます。
⏱ 約3分 資金計画を立てる
TOOL 03
購入コスト全体像ツール
物件価格だけでは見えない、仲介手数料・登記費用・修繕積立金などの初期費用から35年間のランニングコストまで総合的に把握。新築・中古・戸建ての比較にも対応。
⏱ 約3分 コストを把握する
TOOL 04
賃貸 vs 購入 比較
今の家賃と購入した場合の月々返済を35年で比較。損益分岐点を自動で算出し、購入に踏み出すタイミングを数字で判断できます。
⏱ 約2分 比較してみる
TOOL 05
エリア診断
子育て・通勤・価格帯・生活利便性など、あなたの優先事項に合わせてエリアをスコアリング。最大3エリアを並べて比較でき、住み替え先の絞り込みに役立ちます。
⏱ 約5分 エリアを診断する
TOOL 06
子育て診断
子どもの年齢・フェーズ（乳幼児／小学生／中学生）に合わせた学区・保育施設・公園情報をスコアで確認。住み替え先の子育て環境を客観的に比べられます。
⏱ 約4分 子育て環境を診断する
