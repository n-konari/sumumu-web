TOOL 02 統合ツール
借入可能額 ＆ 住み替え資金計画
年収・勤務形態から最大借入可能額を算出。住み替えモードでは現マンションの売却想定価値 → 残債控除 → 新規借入額まで3ステップで完結。他ポータルにない一貫した設計です。
できること（2つのモード）
  • Aモード：年収・勤続年数から借入可能額の上限・目安を算出
  • Aモード：返済負担率ゲージで無理のない借入額を把握
  • Bモード：現マンションの売却想定価値を簡易試算
  • Bモード：残債控除 → 手取り → 新規借入額を自動計算
